# Eye Suites Dashboard

Modern Next.js command center for ophthalmic Office-Based Surgery clients at `dashboard.eyesuites.com`.

## Stack

- Next.js App Router
- Tailwind CSS
- shadcn/ui-style reusable components
- lucide-react icons

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000/dashboard`.

## Verification

```bash
npm run lint
npm run build
```
